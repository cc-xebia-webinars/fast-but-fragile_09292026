## Webinar Overview

### Description

AI tools accelerate output, but velocity without guardrails accumulates risk fast. This session looks at what code quality means when machines write much of the code, and how to measure and defend it without slowing your team to a crawl.

### Agenda

-   Why AI-generated code shifts the quality conversation: volume, plausibility, and the "looks right" problem
-   The quality dimensions that matter most under AI assistance: correctness, maintainability, security, and test coverage
-   Metrics worth tracking, and the vanity metrics that mislead, for AI-heavy workflows
-   Where AI code tends to break: subtle logic errors, outdated patterns, hallucinated APIs, and silent security gaps
-   Building a review and testing safety net: human review, automated gates, static analysis, and CI checks tuned for AI output
-   Establishing team standards and prompts that bias AI toward quality from the start
